## Evidence rules and source coverage

- **Verified:** inspected evidence supports the stated, limited fact.
- **Partial:** evidence supports part of the requirement, with the remaining part named.
- **Awaiting confirmation:** a specific fact needs an attributable response.
- **Missing original record:** no supporting original was located in the inspected sources. This does not mean the activity did not happen.
- **Not applicable:** use only with an explicit applicable scope decision; none of the four consultation/standup/retro requirements is waived here.

A source test demonstrates intended coverage; a recorded test execution demonstrates only that environment/revision. A merge establishes integration. Deployment and deployed verification require separate records. Neither commit activity nor PR authorship establishes attendance, individual effort, actual product-owner duty or instructor approval.
