# Twemoji artwork

Ingredient emoji artwork by Twitter, Inc. and other contributors, from
[Twemoji v17.0.3](https://github.com/jdecked/twemoji/tree/v17.0.3/assets/svg).

The 54 SVGs in `svg/` are unchanged copies: each was compared byte for byte to
that upstream tag on 27 November 2026. Mori's Mix serves them locally as
ingredient illustrations; no Twemoji JavaScript source is bundled here.
